{% trans "Perguntas frequentes" %}

{% trans "Em que moeda eu preencho os preços?" %}

{% trans "Sempre em ¥ (RMB), por chip. O número que você digita é o que fica guardado — a conversão para US$ é feita pelo sistema, com a taxa do contrato exibida no topo." %}

{% trans "E se a taxa do contrato mudar?" %}

{% trans "Os seus preços em ¥ não mudam. Só muda o valor em US$ que o sistema calcula a partir deles." %}

{% trans "Meu preço vale na hora?" %}

{% trans "Não. Toda mudança passa primeiro pela revisão do WhatTheChip. Depois de aprovada, vale na hora — e você recebe uma notificação." %}

{% trans "O que significa “em revisão”?" %}

{% trans "Sua mudança foi enviada e aguarda aprovação. Até lá, o valor antigo continua valendo." %}

{% trans "Errei um preço. Posso corrigir?" %}

{% trans "Sim. Envie o valor certo na mesma linha — o novo pedido substitui o anterior." %}

{% trans "O que é a linha amarela?" %}

{% trans "É um chip sem cotação — falta você dar o preço. O contador da página Início mostra quantos faltam." %}

{% trans "Para que serve a tabela “Outras marcas”?" %}

{% trans "É a sua tabela geral. Esses preços valem para chips de qualquer marca que não tem tabela própria." %}

{% trans "Está faltando um chip na minha tabela?" %}

{% trans "Fale com o WhatTheChip — nós adicionamos a linha e ela aparece para você cotar." %}
