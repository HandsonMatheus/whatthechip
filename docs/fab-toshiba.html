4.5 Toshiba / Kioxia 🇯🇵 Japão · Toshiba Memory renomeada para Kioxia em 2019/2020
Tipos produzidos: eMMC · eMCP · uMCP · UFS · NAND bruta

A divisão de memória da Toshiba foi reestruturada e renomeada para Kioxia. A fabricante é pioneira na tecnologia flash. Os chips fabricados antes da mudança carregam o prefixo TH ou TC, e a Kioxia manteve essencialmente o mesmo padrão de nomenclatura. A série TY identifica fisicamente os componentes eMCP (armazenamento + RAM híbridos), onde a letra após a raiz indica a geração da memória volátil integrada.

Tipo Prefixo gravado no chip Observação para triagem / RAM integrada
eMMC THGBM... / THGBF... / THGBJG... Armazenamento mobile. Padrões clássicos BGA 153 e 169.
eMCP TYBB... / TYBC... Com LPDDR2 (baixa viabilidade para mercado reacondicional).
eMCP TYBD... / TYBE... Com LPDDR3.
eMCP TYBF... Com LPDDR4.
eMCP TYCO... Com LPDDR4X.
eMCP / uMCP TYDO... Com LPDDR5.
UFS THGJF... / THGUF... Armazenamento serial de alta velocidade.
NAND bruta TH58... / TC58... TC58 é extremamente comum em sucatas mais antigas. TH58 é geralmente usado para die com densidades maiores.
Dica de esteira: A sequência TY para componentes híbridos é progressiva e cronológica. Memorize o padrão visual: BB/BC (LPDDR2) → BD/BE (LPDDR3) → BF (LPDDR4) → CO (LPDDR4X) → DO (LPDDR5).
