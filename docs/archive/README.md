# Arquivo de notas de sessão (histórico)

Esta pasta guarda **notas de handoff de sessões antigas**, mantidas apenas como
registro histórico. **Elas NÃO são fonte da verdade** e podem conter informação
desatualizada (ex.: Gemini descrito como camada ativa — hoje é legado e desligado
por padrão, `GEMINI_ENABLED=false`).

- ➡️ Para onboarding e regras atuais, use o **`CLAUDE.md`** na raiz do projeto.
- ➡️ Para decisões de arquitetura e histórico de bugs, use **`HANDOFF.md`** na raiz.
- ➡️ Em caso de dúvida, **o código vence** (`chips/engine.py`, `core/settings.py`).

**Convenção para novas notas de handoff:** nomeie com data, ex.:
`2026-06-14-handoff.md`. Não crie `NEXT_CHAT.md` soltos na raiz do projeto.
