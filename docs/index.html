Sobre esta documentação

Guia prático para identificar, classificar e avaliar chips de memória e processamento vindos de placas descartadas — de DDR1 até UFS 4.0 e LPDDR5X. Construído para operadores de triagem, analistas e compradores do mercado de refurbishing e reciclagem eletrônica.

Cobre Part Numbers de 11 fabricantes ativos e 1 histórico (Elpida), com tabelas de decodificação, metodologia de detecção de chips remarked e hierarquia de viabilidade comercial.

Fabricantes cobertos
  • Samsung — eMMC, eMCP, uMCP, UFS, LPDDR, DDR
  • SK Hynix — eMMC, eMCP, UFS, LPDDR, DDR, GDDR
  • Micron — LPDDR, DDR, NAND, GDDR
  • Elpida — DDR2/DDR3 (legado, absorvida pela Micron)
  • Toshiba / Kioxia — eMMC, UFS, NAND
  • SanDisk / WD — eMMC, UFS, NAND
  • Nanya Technology — DDR2/DDR3/DDR4
  • Kingston — DDR, módulos de memória
  • Rayson — NOR Flash, eMMC de baixo custo
  • ISSI — SRAM, NOR Flash, DRAM
  • GigaDevice — NOR Flash, eMMC
Tipos de chip cobertos
  • eMMC — Armazenamento NAND gerenciado (4.4 → 5.1)
  • eMCP — eMMC + LPDDR em package único
  • uMCP — UFS + LPDDR5 em package único
  • UFS 2.x / 3.x / 4.0 — Armazenamento de alta velocidade
  • LPDDR3 / LPDDR4(X) / LPDDR5(X) — RAM de mobile
  • DDR3 / DDR4 / DDR5 — RAM de notebook e desktop
  • GDDR5 / GDDR6 — RAM de GPU
  • NAND Flash (raw) — Armazenamento bruto (SSD, pendrive)
  • NOR Flash — Firmware de roteadores, TVs, STBs
  • SRAM — Cache em equipamentos industriais
  • CPU / SoC — MediaTek, Qualcomm, UNISOC, Allwinner
