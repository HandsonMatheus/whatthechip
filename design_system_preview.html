WhatTheChip v2.0

Sistema de design baseado no IBM Carbon White theme com três extensões proprietárias: tipografia Helvetica Neue, gradientes de aquecimento visual para o mercado asiático e base em 14 px para densidade operacional. Esta página demonstra todos os componentes em uso real no sistema Django — fonte de verdade em static/css/style.css.

08 — Gradientes (extensão WTC sobre Carbon flat)

Carbon vanilla é completamente plano. O WTC adiciona gradientes para aquecimento visual no mercado asiático. Um implementado (hero), quatro propostos para próximos sprints. Regra: máximo 3 pontos de cor, nunca em texto de resultado.
